# diagrama
Este archivo HTML presenta un diagrama visual de la arquitectura de base de datos del proyecto SportyStyle, una tienda online de ropa deportiva.  El diseño muestra de forma clara el flujo completo del sistema en una arquitectura de 3 capas.
Arquitectura del sistema

El sistema está compuesto por las siguientes capas:

👤 Cliente: Usuario que navega, agrega productos al carrito y realiza compras
🌐 Frontend: Desarrollado con HTML5, CSS3 y JavaScript
⚙️ Backend: Node.js + Express (gestión de lógica de negocio y API REST)
🗄️ Base de datos: MySQL (modelo relacional)

Características principales
✔️ Transacciones ACID para asegurar integridad de datos
✔️ Consultas parametrizadas (prevención de SQL Injection)
✔️ Control de inventario en tiempo real
✔️ Registro de accesos (auditoría)
✔️ Arquitectura escalable y organizada

Tecnologías utilizadas
HTML5
CSS3
JavaScript (Vanilla)
Node.js + Express
MySQL (XAMPP)
